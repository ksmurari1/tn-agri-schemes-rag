# Application screenshots and visual assets

This folder is intended for **real screenshots captured from the running application** and exported diagrams. This documentation pack does not include fabricated application screenshots.

## Recommended screenshots

| Filename | Capture | Suggested caption |
|---|---|---|
| `app-home.png` | Home page | A guided entry point to Tamil Nadu agriculture scheme information. |
| `ask-assistant.png` | Ask AI Assistant with a useful answer | Ask in Tamil or English and inspect the supporting sources. |
| `source-evidence.png` | Expanded source details | Review passages and metadata that support an answer. |
| `sources-ingestion.png` | Sources & Ingestion page | Prepare trusted PDFs, URLs, and selected Government Orders for indexing. |
| `go-catalogue-review.png` | Catalogue preview/selection | Review records before choosing documents to ingest. |
| `knowledge-base-status.png` | Knowledge Base Status | Inspect registered sources and export metadata. |
| `voice-question.png` | Transcript in the question box | Review and edit a transcribed question before sending. |
| `architecture.png` | Exported architecture diagram | See the ingestion, retrieval, answer, and evidence paths. |

## Embed screenshots in Markdown

Once real screenshots exist:

```markdown
![Application home page](images/app-home.png)

```

## Capture checklist
- [ ] Capture from the current running application.
- [ ] Use a consistent browser size/zoom and readable text.
- [ ] Remove credentials, private paths, and sensitive source content.
- [ ] Match the filename and case exactly to Markdown links.
- [ ] Use PNG for UI screenshots and SVG/PNG for diagrams.
- [ ] Prefer focused images that explain a capability over decorative images.
